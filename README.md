# Kismet CMS

The Kismet CMS project is designed to digitize, streamline and automate compliance processes across all major affordable housing subsidy programs (Section 8, LIHTC, Public Housing, RAD, etc.), while allowing for state-level rule implementation. The system currently provides document/data storage for resident files/forms for the subsidy lifecycle, allows for detailed resident file audits (internal/external QC review), EIV "master file" and "tenant file" reporting and discrepancy management, and helps organizations prepare for the Management and Occupancy Review (MOR) process by consolidating required documents and data in one place, with role-based access controls for various industry stakeholders including CAs, investors, and state/federal agencies to access specific documents/data.

I view Kismet as a long-term infrastructure project designed to meet HUD's outlined goals in the 2024 Budget in Brief, namely [Strategic Goal #5](https://www.hud.gov/sites/dfiles/CFO/documents/2024-Budget-in-Brief-Final.pdf#page=11), and [Management and Administration improvements](https://www.hud.gov/sites/dfiles/CFO/documents/2024-Budget-in-Brief-Final.pdf#page=36) that are needed in the department to enhance the long-term sustainability of HUD's programs.

This is a 10-15 year project implementation due to the complexity of affordable housing regulations and compliance requirements, and the vast array of stakeholders such a software system needs to serve in order to solve the problem at its root.
